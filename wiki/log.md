Two bytes of one unit's prefix -- the smallest useful size for the finding, since any larger would have been chased in the source.

* **Create**: [Every element read costs fourteen bytes and goes through the frame twice](/observations/nested-static-link/observation.md). Two cases, and the blind spot is the trap that goes with it: naming an enclosing variable inside an `asm` block resolves it against the nested frame, compiles cleanly, and is wrong at run time.
